Check the player All Skills bonus

One destination, one trait, and a +1 or +2 All Skills roll. Keep the result easy to compare.

1. Prepare data2. Configure3. Use the map4. Adapt it

What to create or confirm

Confirm Level 2 is a usable destination and stat_id = 127 is item_allskills in your mod. Use an existing learned skill to compare its displayed level before and after entering the map.

These examples use one Identify Scroll (isc). Create an exact isc → Red Portal CubeMain recipe: follow the plain-scroll recipe instructions, replacing its tsc input with isc. The TOML route alone does not create this recipe. Confirm IDs against your effective mod data using the ID lookup guide.

The decisions in this configuration

The only trait is player_all_skills, its only stat targets player, and the only group’s pool contains that trait. A count of exactly 1 guarantees its selection. The value still rolls between +1 and +2.

Density is 100%. This small example has no tier or group base_stats, so there is no additional fixed monster life bonus to confuse the comparison.

# Complete example. Requires an exact isc -> Red Portal CubeMain recipe.
# Use the Level IDs and stat IDs from your effective mod data.
config_version = 1
enabled = true
random_salt = "native-mapping"

[hud]
enabled = true
density_text = "Monster Density: {value}%"
overflow_text = "+{value} more"
max_lines = 16

[traits.player_all_skills]
weight = 100
text = "Player All Skills {signed}"
stats = [
  { stat = "item_allskills", stat_id = 127, value = { min = 1, max = 2, step = 1 }, target = "player" }
]

[cube_routes.identify_scroll]
inputs = ["isc"]
tier = "tier1"

[tiers.tier1]
trait_count = { min = 1, max = 1 }

[tiers.tier1.groups.field]
weight = 100
levels = [2]
entrances = [{ level = 2, weight = 100 }]
density = 100
trait_pool = ["player_all_skills"]

Close the game, keep your current configuration if needed, and save this complete file as <scope>/d2rloader/config/native-mapping.toml. Restart the game and loader. Do not append it to another complete configuration.

What to check in the map

Where to checkExpected comparison
Outside the mapRecord the displayed level of a learned skill with the same equipment.
Inside Level 2The automap should show Player All Skills +1 or +2. Compare the learned skill’s displayed level with the recorded value.
After leaving the mapCompare again to check that the map bonus is no longer applied.
Another craftAll Skills remains the only trait, but the rolled value can be the same as before.

Use the recipe, enter its portal, and open the automap. Before a later craft replaces a map, collect needed items and corpses and move all players and allies out of every affected Level. See the repeat-craft procedure. Configuration parsing and map rolls are checked separately from gameplay; confirm the effects in your own mod.

Change the behavior intentionally

For a fixed +1 comparison, change the stat’s value to 1. To check mana next, replace the trait with player_maximum_mana or player_mana_regeneration from the full example, and change the pool reference to match. Keep the count at 1 while isolating an effect.
