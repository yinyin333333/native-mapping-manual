Give each region its own traits

Five destinations share one tier, but each offers a different set of player bonuses and monster challenges.

1. Prepare data2. Configure3. Use the map4. Adapt it

What to create or confirm

Use the Pit, Arcane Sanctuary, Travincal, Chaos Sanctuary and Worldstone Keep groups from the larger example. Their original monsters remain in place. This file changes density and traits, without replacing monster pools.

These examples use one Identify Scroll (isc). Create an exact isc → Red Portal CubeMain recipe: follow the plain-scroll recipe instructions, replacing its tsc input with isc. The TOML route alone does not create this recipe. Confirm IDs against your effective mod data using the ID lookup guide.

The decisions in this configuration

The five weights add up to 500. Each map draws exactly two distinct traits from its own three-entry pool. All traits have equal weight; being defined in traits does not make a trait available to every group.

What to check in the map

An Arcane Sanctuary roll can give All Skills +1 and Maximum Mana +20%, or any other pair from its three candidates. It cannot draw Conviction from the Worldstone Keep pool. In Travincal, the random monster life bonus adds to the fixed tier bonus when selected.

The Worldstone Keep pool may select Conviction, but it is not guaranteed: two of its three traits are chosen. An elemental monster trait only helps a monster when its attacks or skills can use that stat.

Use the recipe, enter its portal, and open the automap. Before a later craft replaces a map, collect needed items and corpses and move all players and allies out of every affected Level. See the repeat-craft procedure.

Change the behavior intentionally

  • Guarantee All Skills in Arcane Sanctuary: add forced_traits = ["player_all_skills"] to that group. With the existing count of 2, the result is All Skills plus one other trait.
  • Guarantee all three caster bonuses: set that group’s trait_count = { min = 3, max = 3 }.
  • Add a sixth destination: copy a group table, give it a unique ID, change its Levels and entrance, and choose its pool. Recalculate probabilities using the new total weight.
  • Change only one region: edit its trait_pool or density. Editing a shared trait definition changes that trait wherever it is used.
